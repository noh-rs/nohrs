Launcher × Explorer

Nohrs is a keyboard-driven file explorer for macOS with a built-in launcher. Written in Rust. Open source, and still pre-alpha.

There is no release to download yet. To try it today, build it from source on macOS. 

$git clone https://github.com/noh-rs/nohrs
$cargo run -p nohrs

Maker's note

Looking for a file is not work.

On a stock Mac, reaching a file means opening a window, walking down a hierarchy, then switching to a search field when that fails. Each step is small. Together they are most of the time you spend on files.

Nohrs puts a launcher and an explorer in one application to remove those steps. Summon it with a global hotkey, move to where you are going with the keyboard, and preview or act on the file in the same window. We want to do only that — quickly and reliably.

Rust and gpui were chosen so that “quickly and reliably” never has to be traded away. It is still pre-alpha, and there is more that it cannot do than can. The whole process is in the open.

Why Nohrs

Four things it refuses to compromise on.

A launcher, not an afterthought

A built-in launcher you summon from a global hotkey — designed with the explorer, not added to it later.

Everything a modern file manager owes you

Split view, tabs, drag-and-drop and bulk operations — the baseline, done properly.

Sandboxed WASM components

Extend Nohrs in Rust, TypeScript or Python. Every plugin runs sandboxed under an explicit-consent permission model.

No dependency on the OS index

A self-contained SQLite + Tantivy hybrid index that understands code bases — it does not wait on the system search daemon.

Roadmap

Six phases, shipped in order.

P1 iterates on 0.0.x. The first usable build is cut as 0.1.0 when P2 completes.

P1 0.0.x Foundation — quality, workspace split, dev/CI infrastructure, web In progress
P2 0.1.0 Explorer essentials — drag-and-drop, file operations, split view, tabs, persistence Planned
P3 0.2.0 Launcher & search — global-hotkey launcher, SQLite FTS5 search Planned
P4 0.3.0 Plugin host — WASM component model, templates for three languages Planned
P5 0.4.0 Ecosystem — plugin store, community plugins Planned
P6 0.5.0 Stabilization — multi-OS strategy, performance gates, documentation Planned

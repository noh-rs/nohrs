ポインタでできることには、それより速い打鍵があるべきだと考えています。エクスプローラーはその基準で評価しており、キーが割り当てられていない操作は「好みの問題」ではなく不具合として扱います。

## 移動する

| キー | 動作 |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | アクティブな行を動かす |
| <kbd>→</kbd> | 選択中のディレクトリに入る |
| <kbd>←</kbd> | 親ディレクトリへ戻る |
| <kbd>⏎</kbd> | 選択中のファイルを開く |
| <kbd>⌘</kbd><kbd>↑</kbd> | 親ディレクトリへ戻る |

## 選択する

| キー | 動作 |
| --- | --- |
| <kbd>⇧</kbd> + クリック、<kbd>⇧</kbd><kbd>↑</kbd> <kbd>⇧</kbd><kbd>↓</kbd> | アンカーから選択範囲を伸ばす |
| <kbd>⌘</kbd> + クリック | 1 行だけ追加／解除する |
| <kbd>⌘</kbd><kbd>A</kbd> | 現在のディレクトリ内をすべて選択 |
| <kbd>esc</kbd> | 選択を解除する |

<Callout>
<kbd>esc</kbd> は、解除すべき選択があるときだけ消費します。他の用途に押した escape を黙って飲み込むキーは、割り当てが無いことより悪いためです。
</Callout>

## ファイルを操作する

| キー | 動作 |
| --- | --- |
| <kbd>⌘</kbd><kbd>C</kbd> / <kbd>⌘</kbd><kbd>V</kbd> | コピーし、現在のディレクトリに貼り付ける |
| <kbd>⌘</kbd><kbd>⌥</kbd><kbd>V</kbd> | コピーではなく移動する |
| 選択中の名前の上で <kbd>⏎</kbd> | その場でリネームする |
| <kbd>⌘</kbd><kbd>⌫</kbd> | ゴミ箱へ移す |

ボリュームを跨ぐ移動は、コピーしてから削除する動作になります。瞬時に終わったように見せず、そのとおりに表示します。

Nohrs is a keyboard-driven file explorer for macOS. It is written in Rust on top of
[gpui](https://github.com/zed-industries/zed), the GPU-accelerated UI framework Zed is
built on.

<Callout title="macOS only">
Nohrs runs on macOS 13 or later, on Apple silicon and Intel. Whether it goes further than
that is a decision the project has not made.
</Callout>

## What it does

- Browsing the file system with the keyboard, in a list or grid view
- A preview pane that renders the selected file — Markdown, code and text
- Multi-select, with click, shift-click and command-click
- File operations: copy, move, rename, create, trash and delete, with cross-volume handling
- Search scoped to one folder or the whole tree, over names or over file contents

## What is still ahead

Two of the things Nohrs is for are on the roadmap rather than in the application:

- **The launcher** — a global hotkey that reaches a folder or a file without a window in
  the way. It arrives in P3.
- **Plugins** as WASM components, each holding only the permissions you granted it. The
  host that runs them arrives in P4.
